Modèle de site VERNIE · mise à jour le 13 novembre 2026

À lire avant d'utiliser ce modèle Vous pouvez reprendre la mise en page et le code de ce modèle. Vous ne pouvez pas publier un site avec les images de cette démo : elles ne nous appartiennent pas. Remplacez toutes les images par les vôtres avant la mise en ligne.

1. Ce site

VERNIE est un site de démonstration : le studio est fictif, les prestations et les prix sont des exemples, et les rendez-vous pris ici sont des essais. Personne ne vous attend à l'heure choisie et aucun acompte n'est demandé.

Éditeur : Kreeative (kreeative.xyz), qui crée ce modèle pour la plateforme Jeere. Hébergement : Vercel Inc. (vercel.com). La page n'est pas référencée par les moteurs de recherche.

2. Les images ne nous appartiennent pas

Les photos de ce site ont été trouvées sur Pinterest et Instagram ; deux portent la signature de leur auteure (@nailsbyandrrea, @aashleysnails).

Elles appartiennent à leurs auteurs et aux personnes qui y figurent. Elles sont utilisées ici uniquement pour illustrer la mise en page, sans aucune vente. Si vous êtes l'auteur ou le sujet d'une image et souhaitez son retrait ou une mention, écrivez à contact.jeere@kreeative.xyz : elle sera retirée sans délai.

3. Si vous reprenez ce modèle

  • La mise en page, les textes d'exemple et le code sont à vous dès que le modèle vous est remis.
  • Les images, elles, ne sont pas incluses : remplacez-les toutes par vos photos (vos poses, vos clientes avec leur accord) ou par des images dont vous avez les droits.
  • Ne téléchargez pas, ne republiez pas et ne revendez pas les images de cette démo.
  • Remplacez aussi le nom, l'adresse, le téléphone, les prestations, les prix et les conditions par les vôtres, dans Jeere › Rendez-vous.

4. Vos données sur cette démo

Si vous faites un essai de réservation, le nom, le numéro et l'e-mail saisis sont enregistrés par Jeere avec ce rendez-vous d'essai, pour montrer le fonctionnement. N'y mettez pas de vraies coordonnées si vous ne le souhaitez pas. Pour faire supprimer un essai, écrivez à contact.jeere@kreeative.xyz.
